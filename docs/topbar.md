# topbar.md

마지막 업데이트: 2026-05-02  
문서 성격: **상단 글로벌 메뉴/페이지 예시 기준 참고 문서 — 완전판 갱신본**

이 문서는 원본 `topbar.md` 가 가지고 있던 역할, 즉
상단 글로벌 메뉴가 실제 페이지에서 어떤 형태로 보이고,
각 페이지의 구성 요소가 어떤 문맥과 예시를 갖는지 정리하는 **참고용 실전 문서**입니다.

원본 문서는 `analysis_export.pdf` 형태의 페이지 예시를 기반으로,
커뮤니티 / 모집 및 의뢰 / 제휴사 및 자유홍보 / 고객센터 / 프로그램 문의 화면이 실제로 어떤 식으로 보여야 하는지 간접적으로 설명하고 있었습니다.

현재 문서는 그 예시 문맥을 유지하면서,
현재 워크스페이스 기준 실제 연결 파일과 구현 상태를 함께 정리한 **완전판 갱신본**입니다.

---

## 1. 이 문서의 목적

이 문서는 단순 메뉴 목록 문서가 아닙니다.  
실제 화면 예시를 바탕으로:
- 상단 글로벌 메뉴가 어떤 페이지로 연결되는지
- 각 페이지가 어떤 정보 구조를 가지는지
- 어떤 배너 / 탭 / 게시판 / 모달이 있어야 하는지
- 기존 버전의 시각적 맥락이 무엇이었는지
를 설명하는 참고 문서입니다.

즉,
`TOPBAR_FEATURES_SPEC.md`가 Why/What/How를 규정하는 명세 문서라면,
`topbar.md`는 **실제 예시 화면 중심의 레퍼런스 문서**라고 볼 수 있습니다.

---

## 2. 원본 기준 예시 페이지 묶음
원본 `topbar.md`에는 대략 아래 파일들의 예시가 포함되어 있었습니다.

- `frontend/app/community/board.html`
- `frontend/app/escrow/missions.html`
- `frontend/app/partner/services.html`

즉, 상단 글로벌 메뉴가 연결하는 핵심 5개 페이지를 중심으로,
사용자가 실제 어떤 화면을 보게 되는지에 대한 기준 자료였습니다.

현재 구현은 게시판형 페이지들과의 일관성을 더 강하게 가져가는 방향입니다.

## 10. 현재 구현 특징 (2026-05-02 기준)

- 높이 64px

- `/app/...` 기준 유지

- 공지사항/가입인사/출석체크는 검색 없음
- 자유게시판/정보공유/로직분석 연구실만 검색
- 상세/댓글/출석체크 API 연결 준비 중

## 11. 이 문서의 사용 방식
이 문서는 앞으로 다음 상황에서 참고해야 합니다.

1. 상단 글로벌 메뉴의 페이지별 예시를 다시 복원할 때
2. 원본 PDF 추출/예시와 현재 구현을 비교할 때
3. 페이지 통일성이 어색한지 판단할 때
4. 기획자가 “원래 이 페이지 이런 느낌 아니었나?”를 확인할 때
5. 새 채팅에서 탑바/페이지 구조를 넘길 때

즉,
이 문서는 단순 구조 문서가 아니라,
**탑바가 연결하는 각 페이지의 화면 문맥과 예시를 기억하기 위한 레퍼런스 문서**입니다.

---

## 12. 최종 선언
탑바와 그 하위 페이지는 단순 라우팅 묶음이 아닙니다.  
커뮤니티는 체류/소통,
제휴사는 수익화,
모집 및 의뢰는 핵심 에스크로,
프로그램 문의는 VOC,
고객센터는 운영/CS 효율화라는 각기 다른 역할을 갖습니다.

따라서 이 문서는 메뉴 연결 정보뿐 아니라,
각 페이지가 어떤 예시와 어떤 문맥으로 보여야 하는지를 유지하는 기준으로 사용해야 합니다.
