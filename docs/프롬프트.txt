## 제공 방법

```
새 채팅에서:

1. 마스터 프롬프트 붙여넣기
2. 스타일 가이드 붙여넣기
3. CURRENT_STATUS 붙여넣기
4. config.js + app.css + sidebar.js + topbar.js + api.js + auth.js + dashboard.html 붙여넣기
5. "Phase B 시작 — login.html 만들어줘" 식으로 요청
```

> **index.js**는 프론트엔드만 작업할 때는 안 줘도 됩니다. 백엔드 엔드포인트 추가/수정이 필요한 작업일 때만 함께 제공하면 됩니다. (파일이 워낙 길어서 불필요하게 제공하면 컨텍스트만 낭비)

> **schema.sql**, **wrangler.toml**은 DB 구조 변경이 필요한 작업이 아니면 제공 불필요합니다.
